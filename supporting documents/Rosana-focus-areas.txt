This is a hierarchy of focus areas that a user can select when creating a Project in Rosana.

This hierarchy appears in the Project editor page as a series of dropdowns. The first dropdown lists the main and second categories of focus area (e.g., Road User - Vulnerable Road Users). A second dropdown populates on selection of the first dropdown, and it lists all subcategories of the selected supercategory.
